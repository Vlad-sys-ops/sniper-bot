# Правила торговой системы Снайпер 4.0

## 1. Блоки Ордеров (Короба)
- **Определение:** Зона консолидации, где маркетмейкер набирает толпу.
- **Границы:** Строятся **строго по телам свечей** (Open/Close). Шпили (High/Low) игнорируются.
- **Цвета:** 
  - Черный — блок формируется (цена внутри).
  - Синий — цена вышла из блока ВВЕРХ (ММ в позиции Бай).
  - Красный — цена вышла из блока ВНИЗ (ММ в позиции Селл).
- **Расширение:** Если цена заходит обратно в блок и не проходит 40% его ширины, блок расширяется (границы перерисовываются).
- **Длина:** Заранее неизвестна, может длиться неделями. Минимум для валидации — 5 баров H1.

## 2. Блок Пустых Цен (БПЦ)
- **Определение:** Свеча или группа свечей с сильным импульсом (без откатов). Движение к стопам толпы.
- **Правило 90%:** Если цена подходит к противоположной границе БПЦ, она закроет его минимум на 90%.
- **Расположение:** БПЦ не должен пересекаться с Блоками Ордеров.
- **Вход:** Строго после формирования БПЦ (не внутри него).

## 3. Тренд и Контекст
- **Тренд:** Это скопление Блоков Ордеров в одном направлении (минимум 3 блока).
- **Коррекционный блок:** Блок против тренда, который не меняет тренд. Приоритет — торговля против глобального тренда, но половинным лотом.
- **Разворотный блок:** Блок H1, который находится у границы крупного блока H4 (в пределах 10% от ширины). Вероятность разворота — 70-90%. Приоритет меняется на противоположный.

## 4. Точки входа (Шаблоны)
1. Вход у границы уже сформированного блока (по тренду).
2. Вход в новом (формирующемся) блоке.
3. Вход после расширения сформированного блока.
4. Вход во время расширения (только по тренду, первые 2-3 блока).
5. Вход от БПЦ (по правилу 90%).

**Запрещено:** Входить внутри блока (как самостоятельная точка входа).

## 5. Риск-менеджмент (ММ)
- **Категории сделок:**
  - Безопасная (75%): начало тренда, H1 совпадает с H4, сильный блок.
  - Консервативная (60%): стандартная ситуация.
  - Агрессивная (55%): 4+ блок в тренде, H1 против H4, слабый блок.
- **Таблица лотов:** Берется из материалов (зависит от баланса).
- **Стоп-лосс:** За границу блока (по телам) + буфер.
- **Тейк-профит:** Противоположная граница (по тренду) или середина блока (против тренда).

## 6. Специальные тактики
- **Корректировка ордеров (x2):** При срабатывании стопа — повторный вход тем же сигналом, но удвоенным лотом.
- **Закрытый блок:** Использование прибыльной позиции (Ордер-Щит) для открытия противоположных сделок без стопов внутри нового блока. Строгий контроль объема (не больше Ордера-Щита).
