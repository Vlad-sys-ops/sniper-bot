# Sniper 4.0 Trading Bot

Автоматизированная торговая система на Python.

## Технологии
- Python 3.10+
- Linux (Raspberry Pi 4 / VPS)
- API (REST / WebSocket)
- ntfy (уведомления)

## Документация
Все правила торговли и логика работы описаны в папке `docs/`.

## Установка
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите бота: `python src/main.py`
